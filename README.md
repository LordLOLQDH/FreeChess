### ✨ Features

- ♟️ **Vollwertiges Schach** - Alle Regeln, inkl. Rochade, En Passant, Promotion
- 🤖 **Stockfish AI** integriert - Spiele gegen den stärksten Engine der Welt
- 📱 **100% Mobile Ready** - `dvh` + `touch-action` optimiert, kein Scroll-Bug
- 🌙 **Dark by Design** - Gebaut für schwarzen Hintergrund, edles Wasserzeichen
- ⚡ **Ultra Light** - Kein Framework, nur Vanilla JS + Canvas
- 🔊 **Sound Engine** - Eigene Sound.js
- 📊 **Stats & Game UI** - game-ui.js & stats.js
